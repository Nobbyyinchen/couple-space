# 情侣空间 · 全 mock 数据推广片

制作日期：2026-10-31。首版采用 1080 × 1920、30fps、30 秒竖屏，适合视频号、朋友圈及短视频渠道预览。

## 创意与文案

主题：把普通的日子，慢慢写成我们。

沿用奶油白、莓果色、鼠尾草绿和纸张手账风格，通过 React 绘制的 mock 界面呈现图文回忆、共同心愿、相恋计时与纪念日。两位主角为虚构昵称「阿栗」「木木」。所有人物资料和故事、日期、清单、互动数量均为 mock 数据。音乐为本项目程序合成的原创短配乐，无人声。

| 时间 | 主画面与动作 | 画面文案 |
|---|---|---|
| 00–04 秒 | 奶油白纸面、植物邮票、海边插画相纸轻轻进入；大字逐行浮现 | 把普通的日子，慢慢写成我们。 |
| 04–10 秒 | 展示 mock 回忆界面：阿栗发布海边手记，木木留言 | 小事，也值得珍藏。／一张照片，一句今天的小开心。 |
| 10–16 秒 | 展示 mock 心愿清单：3 项心愿、1 项已完成 | 和你，还有好多想做的事。／把小期待，写进两个人的清单。 |
| 16–23 秒 | 相恋天数与纪念日两个局部在纸面上组合呈现 | 记得每个值得期待的日子。／相伴的天数，和下一次纪念。 |
| 23–30 秒 | 植物邮票与通用产品名居中，细线收束；末尾稳定停留 | 情侣空间／我们的专属小宇宙／邀请另一半，一起写下第一页。 |

## 功能核对与素材来源

- 产品名为通用的「情侣空间」，不读取小程序的真实品牌或人物配置。
- 图文手记、照片、喜欢和留言：`miniapp/miniprogram/pages/memories/` 与 `pages/detail/`。
- 共同心愿、新增及完成状态：`miniapp/miniprogram/pages/wishes/`。
- 相恋天数与纪念日：`miniapp/miniprogram/pages/home/` 与 `pages/us/`。
- 所有展示界面由 `src/MockScreens.tsx` 绘制，数据统一来自 `src/mock-data.ts`。不使用历史截图或真实业务数据。演示日期固定为 2026-02-14：相恋始于 2025-02-14，共 365 天；2026-03-14 的野餐还有 28 天，2027-02-14 的相恋纪念日还有 365 天。手记发生于演示日期的前一天。数据为制作时人工编写的虚构样例。
- 插画与邮票来自 `miniapp/miniprogram/assets/sample-sea.png` 和 `paper-bloom.png`，沿用项目内已有素材，没有额外生成图片。
- 配乐由 `scripts/make-music.mjs` 合成，谱面与音色均在源码中，可重新生成。

项目资料记录正式发布仍有待完成事项，故结尾没有加入「已上线」「立即搜索」或无法确认有效的小程序码。当前引导为邀请另一半。公开投放前可在确认发布状态后替换末屏入口。

## 可修改项

产品名与副标题在 `src/Root.tsx` 的默认参数中；各段文案与画面在 `src/Promo.tsx`。镜头顺序与时长分别为 4 / 6 / 6 / 7 / 7 秒。所有视频代码位于独立的 `promo-video/` 目录，原小程序源码和云端资料无需修改。
